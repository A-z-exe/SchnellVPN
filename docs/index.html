SchnellVPN

Android VPN client · VLESS Reality · VMess · Trojan · Shadowsocks

SchnellVPN is an Android VPN client built with Kotlin, Jetpack Compose and Xray-core. It supports VLESS (Reality, WebSocket, gRPC, HTTPUpgrade, XHTTP), VMess, Trojan and Shadowsocks, with multiple subscription profiles, QR import, direct config links, split tunneling, per-app auto-connect and hotspot sharing.

Features

  • Protocols: VLESS (Reality / WS / gRPC / XHTTP), VMess, Trojan, Shadowsocks
  • Real data probe: only reports “Connected” after a real request succeeds through the tunnel
  • Multiple profiles: each subscription keeps its own servers
  • QR import and direct config links
  • Split tunneling: choose apps that bypass the VPN (e.g. banking apps)
  • Per-app auto-connect when a selected app is opened
  • Auto-connect on boot and disconnect on screen lock
  • Hotspot sharing (no root, local proxy on port 10809)
  • Glass UI, dark/light theme, animated splash, 24h per-app data usage

FAQ

Is SchnellVPN free? Yes, the source code is public on GitHub and the APK is free to download.

Which protocols are supported? VLESS (Reality, WS, gRPC, XHTTP), VMess, Trojan and Shadowsocks.

Does it work without Google Play Services? Yes. QR scanning is offline (ZXing) and does not require Play Services.

Does hotspot sharing require root? No. SchnellVPN runs a local HTTP proxy on port 10809; devices must set a manual proxy. Transparent hotspot VPN without root is not possible on Android.
