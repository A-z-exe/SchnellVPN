Features

  • Protocols: VLESS (Reality / WS / gRPC / XHTTP), VMess, Trojan, Shadowsocks
  • Real data probe: reports “Connected” only after a real request succeeds through the tunnel
  • Smart server selection: measures every server and joins the fastest; automatic failover
  • Multiple profiles: each subscription keeps its own servers and settings
  • QR import and direct config links
  • Split tunneling (Android) and system proxy (Windows/Linux)
  • Auto-connect on boot and disconnect on screen lock (Android)
  • Hotspot sharing (Android, no root, local proxy on port 10809)
  • In-app updates with resumable downloads and rollback
  • Dark/light theme, Persian / English / German interface

FAQ

Is SchnellVPN free? Yes. The source code is public on GitHub and every build is free to download.

Which protocols are supported? VLESS (Reality, WS, gRPC, XHTTP), VMess, Trojan and Shadowsocks.

Does it work without Google Play Services? Yes. QR scanning is offline (ZXing).

Does hotspot sharing require root? No. SchnellVPN runs a local HTTP proxy on port 10809; other devices set a manual proxy. Transparent hotspot VPN without root is not possible on Android.

Which Windows version should I download? Use SchnellVPN.exe for Windows 10/11 and SchnellVPN-Win7.exe for Windows 7/8/8.1.
